## 输入与权重

一个 PE 计算一个输出通道，输入是同一时间步的两张32×32二值图：

```text
i_input_spike_vector_on[1023]  = ON(0,0)
i_input_spike_vector_off[1023] = OFF(0,0)
最低位对应(31,31)
```

在空闲状态采到 `i_start` 时锁存两幅图。此后外部输入可以变化，不会影响当前帧。忙时的 `i_start` 不作为新请求接收，与原接口约定一致。

`P_KERNEL_ON_WEIGHTS_PACKED`、`P_KERNEL_OFF_WEIGHTS_PACKED` 分别对应 PyTorch `weight[out_ch,0,:,:]` 和 `weight[out_ch,1,:,:]`，核内从左上到右下打包，左上权重在最高16位。ON=输入通道0，OFF=输入通道1。

扫描器仍只扫描一个空间位图 `ON | OFF`，从左上到右下。每次接受事件时保存该位置的两位极性信息。

对每个核位置，贡献为：

```text
contribution = (ON ? sign_extend(weight_on) : 0)
             + (OFF ? sign_extend(weight_off) : 0)
```

两套权重先分别扩为26位，再相加；同位置两极性均有效时不会重复退休。没有乘法器。优化版仍每个空间事件用一拍更新9个位置；9拍版逐个更新9个位置。

有效权重函数显式传入极性，且使用 automatic 局部变量，避免组合敏感性遗漏和多次调用的静态临时变量干扰仿真。

## 保留的释放语义

输出地址保持原反向地址：`1023 - (row*32 + col)`。每次输出的值已经累加完ON/OFF两极性；不输出后续仍可能变化的部分和。

优化版仅输出被事件影响过的像素，无输出的位置在重建 current map 时视为0。即使ON/OFF恰好抵消为0，被命中过的位置仍有 active 标记并写回。9拍理解版保留原来的逐像素退休和显式零值输出行为，两版输出包数不要求相同，但完整电流图和active图必须一致。

本阶段没有添加输出 ready 或行完成通知，也没有接 MaxPool。后续池化仍需正确处理缺失零值和完成前沿，不能直接按四个连续 valid 当作一个窗口。

## 32行收尾修正

原 `LP_ROW_WIDTH+1` 在32行时仅得到6位有符号行号，范围为-32到31。收尾需要表示32和33，因此会回绕。本版改用 `$clog2(P_INPUT_HEIGHT+2)+1`，32行时为7位。两个双极性版本都应用该修正，原主线文件不改。

周期对照副本只修正这一位宽，以便原控制逻辑能够在32×32下正常完成；不能将该副本称为未经修改的原28×28基线。

## 位宽与存储

权重16位，电流26位。二值双极性3×3卷积每个输出最多18个权重贡献，即使全为16位极限值也能放入26位累加器。黄金模型使用整数权重，借助float64稠密conv2d计算，本测试范围内整数运算结果精确可表示。

训练权重采用round-to-even后饱和到signed Q4.12，不经过10位小数TXT中转。这里只验证该定点卷积，与浮点分类准确率不是同一项验证。

每个PE保留 `2×32×26 + 3×26 = 1742` 位partial sum数据存储；新增两幅输入快照共2048位和2位事件极性寄存器。这里只是RTL声明级计数，不等于综合FF/LUT结论。四通道实例仅用于验证不同卷积核，尚未决定生产通路的并行或复用方式。

每种权重配置99帧，分别是定向15帧、固定种子随机64帧、实际训练样本10帧、实际官方测试样本10帧。四种权重配置为普通有符号整数、16位极限值、ON/OFF相反权重、seed2026第80轮卷积权重。实际输入只选固定样本验证层计算，不运行分类、不做测试集选模。

每帧验证四个输出通道和两种PE，包括完整电流图、active图、输出无重复且空间有序、frontier溢出、旧值退休后不再修改、换行时frontier已排空、连续帧和开始后外部输入变化。

每帧还比较优化双极性版与32行对照版的总周期、输出写次数，确认相同空间事件流下没有控制周期回退。PROCESS周期数必须分别等于空间事件数和9倍空间事件数。

逐帧周期和运行源码哈希见各权重目录下 `result.json`，仿真日志见 `simulation.log`。尚无Vivado综合、布局布线、Fmax或完整网络准确率结果。
